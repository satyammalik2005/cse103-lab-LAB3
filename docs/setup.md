# Setup Guide

## Prerequisites

- Python 3.8 or higher
- Git 2.x or higher

## How to Run

Clone the repository:

```bash
git clone https://github.com/satyammalik2005/cse103-lab-LAB3.git
cd cse103-lab-LAB3
```

There was no `main.py` in the repository when this guide was prepared. Once an application script is added at `src/main.py`, run it with:

```bash
python3 src/main.py
```
